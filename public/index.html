      MCP

      Piloter Prospecto depuis Claude

      Le serveur MCP passe par cette appli : garde npm start lancé. Puis, depuis le dossier du projet :

      claude mcp add prospecto -- node "$PWD/mcp.js"

      Autre port ou machine : variable PROSPECTO_URL (défaut http://127.0.0.1:3000).

      • scan_city : commune ou rue
      • scan_radius : cercle autour d'un point
      • stats : contenu de la base
      • export : CSV filtré (save_to)
      • list_places : prospects d'une zone
      • check_place : revérifie l'absence de site
